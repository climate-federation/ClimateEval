    """pcolormesh with the coordinates projected up front.

    Two things go wrong with the obvious forms on a GeoAxes:

      * omitting transform= makes cartopy read lon/lat as projection
        metres, so a degree grid collapses to a speck at the origin;
      * passing transform=PlateCarree() makes cartopy push every quad's
        geometry through cartopy.trace -> shapely, which raises
        "ufunc 'create_collection' not supported for the input types"
        on the cartopy/shapely pairing in this environment.

    transform_first would avoid the second, but pcolormesh does not
    accept it in any cartopy version - that argument is contourf only.
    So the points are projected here and pcolormesh is handed
    coordinates already in the axes' projection, with no transform=.

    Longitudes are folded to [-180, 180) and sorted so the periodic seam
    falls at the edge of a central_longitude=0 map. Any cell still
    spanning a large fraction of the map width is blanked: after
    projection such a cell draws as a band across the whole figure.
    """
    lon = np.asarray(lon, dtype=float)
    lat = np.asarray(lat, dtype=float)
    vals = np.array(values, dtype=float)

    if lon.ndim == 1:
        wrapped = ((lon + 180.0) % 360.0) - 180.0
        order = np.argsort(wrapped)
        lon2d, lat2d = np.meshgrid(wrapped[order], lat)
        vals = vals[..., order]

    return ax.pcolormesh(x, y, vals, **kwargs)
